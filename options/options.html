    Site mappings

    Every website lays out verses differently. A mapping tells Śloka Slides which box on the page holds the verse number, the Devanāgarī, transliteration, word-for-word, translation and purport. The easiest way is to open a verse page, click the extension and choose Map this site — then just point and click. Mappings work for single-verse pages and for pages that list a whole chapter.

      How to use

      1. One verse: open the verse page and click the toolbar icon → Present this page (or press Alt+Shift+S).
      2. Some verses from a chapter page: select them with the mouse, then present — only the selected verses become slides.
      3. Verses spread over many pages: on each page choose Add to collection (Alt+Shift+A), then Present collection. Or select several links on a chapter’s contents page and choose Present linked pages.
      4. Any text: copy it and use Paste text.
      5. During the class press T for quick tools (font, size, spacing, theme), G for the verse list and search, ? for all shortcuts.
      6. Resize a section: press + / − (or the A± buttons) on a slide to size that section (verse, word-for-word, translation or purport). The size is saved automatically and used for every verse — the same values as “Relative size of each section” above. Hold Alt for the overall size; 0 resets the section, Alt+0 resets the overall size.
      7. Fix a verse number: hover the number and click ✎ (or press E), type the correct number, and press Enter to save. Useful when a page shows “Text 1, Text 2”.
